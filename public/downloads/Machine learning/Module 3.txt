=== Machine Learning: Module 3 ===
Model Evaluation, Validation, and Deployment

1. Evaluation Metrics:
   - Classification: Confusion Matrix, Accuracy, Precision, Recall, F1-Score, ROC-AUC Curve.
   - Regression: Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), R-squared (R2).

2. Cross-Validation:
   - K-Fold Cross Validation.
   - Stratified K-Fold for imbalanced class distributions.
   - Time-series cross validation for temporal data.

3. Model Serving & MLOps:
   - Model serialization (pickle, joblib, ONNX).
   - Containerization with Docker.
   - REST API endpoints using FastAPI / Flask.
   - Concept Drift vs Data Drift monitoring.
