Server Algorithm:
1. Start the program.
2. Create a UDP socket using socket().
3. Initialize the server address structure.
4. Assign the IP address as INADDR_ANY and port number as 8080.
5. Bind the socket to the server address using bind().
6. Receive an integer from the client using recvfrom().
7. Initialize rev = 0.
8. Repeat while the number is greater than 0:
   - Extract the last digit using num % 10.
   - Reverse the number using rev = rev * 10 + digit.
   - Remove the last digit using num = num / 10.
9. Send the reversed number to the client using sendto().
10. Display the reversed number.
11. Close the socket using close().
12. Stop the program.
Client Algorithm:
1. Start the program.
2. Create a UDP socket using socket().
3. Initialize the server address structure.
4. Assign the server IP address as 127.0.0.1 and port number as 8080.
5. Read an integer from the user.
6. Send the integer to the server using sendto().
7. Receive the reversed number from the server using recvfrom().
8. Display the reversed number.
9. Close the socket using close().
10. Stop the program.
